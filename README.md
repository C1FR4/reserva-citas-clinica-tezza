# Sistema de Reserva de Citas Médicas - Clínica Padre Luis Tezza

Proyecto web para la gestión y reserva de citas médicas de la **Clínica Padre Luis Tezza**.

## 📋 Descripción

Este proyecto contiene la interfaz web para pacientes y administradores de la clínica, permitiendo explorar servicios, especialistas, reservar turnos médicos y administrar consultas.

## 🚀 Estructura del Proyecto

- `index.html` / `index.css`: Página principal y presentación de la clínica.
- `InicioSesion.html` / `iniciosesion.css`: Portal de autenticación de usuarios.
- `PantallaPrincipal.html` / `pantallaprincipal.css`: Panel principal del usuario.
- `Especialista.html` / `especialista.css`: Directorio de médicos y especialistas.
- `ReservarCita.html` / `reservacita.css`: Flujo para agendar una cita médica.
- `DetalleReserva.html` / `detallereserva.css`: Confirmación y detalles de la cita agendada.
- `Medico.html` / `medico.css`: Perfil detallado del médico.
- `Oftalmologia.html`: Información de especialidad.
- `VistaAdministrador.html` / `vistaadministrador.css`: Panel de control administrativo.

## 🛠️ Tecnologías

- HTML5
- CSS3 (Responsive Design)

## 💻 Visualización Local

Para ver el proyecto, abre directamente el archivo `index.html` en cualquier navegador web moderno o utiliza una extensión de servidor local como *Live Server*.
